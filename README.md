# 人工智能原理与应用

深圳大学本科课程学习网站。

本课程从智能体与问题建模出发，通过搜索算法、博弈决策和大模型实践，帮助学生理解人工智能如何解决问题，并学会判断 AI 输出的依据与局限。

## 课程内容

- **认识人工智能**：智能体、PEAS 与任务环境。
- **问题建模与搜索**：状态空间、BFS、DFS、UCS、启发式搜索与 A*。
- **博弈决策**：Minimax 与 Alpha-Beta 剪枝。
- **大模型与 Agent 实践**：文献检索、证据核验与综述辅助。

## 学习资源

网站按 14 次课组织，提供课件、课堂练习、交互实验和拓展阅读。水罐、八数码与罗马尼亚旅行等互动可直接在浏览器中运行。课堂活动以个人实践为主，课后拓展自愿选做。

教材参考《人工智能：一种现代的方法》（第 4 版），具体学习与考核范围以课堂说明为准。
